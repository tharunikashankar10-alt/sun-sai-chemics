SUN SAI CHEMICS - VS CODE WEBSITE
====================================

HOW TO RUN
1. Open this folder in VS Code.
2. Install the "Live Server" extension by Ritwick Dey.
3. Right-click index.html.
4. Choose "Open with Live Server".
5. Your browser will open the website.

IMPORTANT BEFORE CLIENT DELIVERY
1. Replace the brand text with the official logo if the client provides one.
2. Replace placeholder/temporary visual areas with the client's actual company and product photos.
3. Add the client's official phone number and email in contact.html and footer sections.
4. In js/script.js replace CLIENT_EMAIL@example.com with the client's verified enquiry email.
5. Verify the address and Google Maps location with the client.
6. Verify every product name/description with the client.
7. Do not publish certifications, technical specifications or claims unless the client confirms them.
8. Test every page on desktop and mobile.
9. Deploy using Netlify, Vercel, GitHub Pages or the client's hosting.
10. For a custom domain, let the client own the domain/hosting account.

DEPLOYMENT QUICK START
Netlify:
1. Create an account at https://www.netlify.com/
2. Add a new site / deploy manually.
3. Drag the entire project folder into the deploy area (or upload the ZIP after extracting).
4. Netlify gives a public URL.
5. Rename the site if desired.
6. Connect the client's domain only after the client approves and owns the domain.
